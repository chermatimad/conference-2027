# ICEIC 2027 — موقع المؤتمر الدولي الثاني: قضايا اقتصادية معاصرة

واجهة ثنائية اللغة (عربي RTL / English LTR) + لوحة تحكم **Sanity Studio** لإدارة كل المحتوى.
**تطوير: خلية الرقمنة — كلية العلوم الاقتصادية والتجارية وعلوم التسيير، جامعة سطيف 1** · البريد الرسمي: digitalcell.fsecg@gmail.com

## البنية
```
index.html            الواجهة (نفس التصميم السابق)
assets/js/app.js      جلب المحتوى من Sanity + العرض الآمن + التوجيه + اللغتين
assets/data/          fallback.json: نسخة احتياطية تظهر لو تعذّر الوصول إلى Sanity
assets/css, vendor    Tailwind مُصرَّف + خطوط + Font Awesome + AOS (محلية، بلا CDN)
studio/               لوحة تحكم Sanity (المخططات + الهيكل + بيانات الإقلاع)
tools/                أدوات البناء والخادم المحلي
```

## الإعداد لأول مرة (مرة واحدة — تتطلب حسابك على Sanity)
المشروع المستخدم: `k6sogxhu` / dataset: `production` (غيّره في `studio/sanity.config.ts` و`studio/sanity.cli.ts` و`assets/js/app.js` و CSP داخل `index.html`/`_headers` إن استعملت مشروعاً آخر).

```bash
cd studio
npm install
npx sanity login                         # تسجيل الدخول بحسابك
npx sanity cors add https://chermatimad.github.io   # السماح للموقع بقراءة البيانات (بدون credentials)
npm run import-seed                      # يستورد محتوى الموقع الحالي (لا يستبدل ما هو موجود: --missing)
npm run deploy                           # ينشر اللوحة على https://conference-2027.sanity.studio
```
ثم من [sanity.io/manage](https://www.sanity.io/manage) ← المشروع ← **Members** أضف المحررين (Editor) والمسؤولين (Administrator).
للعمل محلياً: `npm run dev` ← http://localhost:3333 (أضف أيضاً `npx sanity cors add http://localhost:3333 --credentials`).

> لا تُنشر المستندات للعموم إلا بعد الضغط على **Publish**. المسودات لا تظهر في الموقع.

## تشغيل/بناء الواجهة
```bash
npm install
npm run build      # ينسخ المكتبات ويُصرِّف Tailwind  (ثم ارفع assets/css/tailwind.css و assets/vendor)
npm run serve      # معاينة على http://localhost:8080
```
ملفات الإخراج (`tailwind.css`, `vendor/`) مُضمّنة في المستودع لأن GitHub Pages يخدم الملفات كما هي.
إن أضفت أصنافاً جديدة داخل `app.js` أعد `npm run build:css`.

## الأمن والأمان (ما نُفِّذ)
- **CSP صارمة**: `script-src 'self'` و`style-src 'self'` بلا سكربتات/أنماط مضمّنة ولا CDN؛ الاتصال الخارجي الوحيد هو قراءة Sanity.
- **منع XSS**: كل نص من لوحة التحكم يمر عبر `esc()`/`textContent`؛ لا `eval` ولا معالجات أحداث مضمّنة؛ الروابط `https` فقط (تُرفض `javascript:`)، الصور من `cdn.sanity.io` فقط، الفيديو يوتيوب بمعرّف صارم (`youtube-nocookie`)، والخريطة من `google.com/maps/embed` فقط. تم اختبار ذلك بحمولات خبيثة في كل الحقول.
- **قراءة فقط من المتصفح**: لا توجد أي رموز (tokens) أو مفاتيح كتابة في الكود. الكتابة حصراً من Studio بعد تسجيل الدخول.
- **نماذج الاتصال/التسجيل** تستخدم `mailto:` نحو البريد الرسمي (لا قاعدة بيانات عامة قابلة للاختراق، ولا تخزين لبيانات الزوار)، مع تنقية الحقول وحدود الأطوال.
- التحقق في Studio: الروابط https فقط، الحدود القصوى للنصوص، صيغ الصور المسموحة، تعطيل إنشاء/حذف الصفحات المفردة.
- الاعتماد "تم تطوير هذا الموقع من طرف خلية الرقمنة…" ثابت في الواجهة ولا يمكن تعديله من اللوحة.

### حدود يجب معرفتها
- **GitHub Pages لا يسمح بترويسات HTTP** (مثل `frame-ancestors` و HSTS)، لذا CSP موضوعة كوسم `meta` (لا تغطي `frame-ancestors`). للحماية الكاملة انشر على Netlify أو Cloudflare Pages؛ الملف `_headers` جاهز.
- اجعل الـ dataset **public** فقط لأنه لا يحوي بيانات حساسة (كل ما في اللوحة يُنشر علناً). لا تضع فيه بيانات شخصية للمشاركين.
- فعّل المصادقة الثنائية (2FA) لحسابات المسؤولين في Sanity، واجعل عدد المسؤولين قليلاً.
- لاستقبال التسجيلات في قاعدة بيانات فعلية لاحقاً: أضف دالة خادم (Netlify Function) بمفتاح كتابة سرّي في متغيرات البيئة — **لا** تضعه في الواجهة أبداً.
